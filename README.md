# To-Do-List
A simple **To-Do List desktop application** developed using **Java Swing** and **Apache NetBeans**.

## Project Structure

```text
ToDoList/
├── src/
│   └── com.mycompany.todolist/
│       ├── Main.java
│       └── ToDoList.java
├── pom.xml
└── README.md
```
## How to Compile and Run

### 1. Clone the repository

```bash
git clone https://github.com/samikhyadas04/To-Do-List.git
```

Navigate to the project directory:

```bash
cd To-Do-List
```

### 2. Open the project

Open the project in **Apache NetBeans IDE**.

Make sure **JDK** is installed on your system.

### 3. Build the project

Using Maven:

```bash
mvn clean package
```

### 4. Run the application

Run the project using Apache NetBeans:

```text
Right Click Project → Run
```

Or press:

```text
F6
```
